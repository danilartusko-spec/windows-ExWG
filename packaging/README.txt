Ex WG {{VERSION}}

Версия для Windows 10/11 x64.

Основной вариант установки:

1. Запустите Ex-WG-Setup-{{VERSION}}.exe.
2. Подтвердите запрос контроля учётных записей Windows.
3. Завершите установку и откройте Ex WG из меню «Пуск».
4. Импортируйте AWG-конфигурацию: QR-изображение, .conf или .zip.

Язык всего интерфейса меняется кнопкой RU/EN справа сверху. Выбор
сохраняется после перезапуска. Исходные строки журнала остаются без
перевода, чтобы не потерять точные ошибки и коды.

После выбора файла Ex WG сразу загружает и проверяет routing.help. При каждом
следующем запуске правила также тихо обновляются в фоне; VPN для этого включать
не требуется.

Крест скрывает Ex WG в системный трей и не отключает VPN. Клик по иконке в трее
возвращает окно; полное завершение выполняется пунктом «Выход / Exit» в её меню.

UseChunkFiles=true в routing-профиле сейчас использует полные совместимые
GeoSite/GeoIP DAT. Все правила применяются; обновление лишь расходует больше
трафика, чем будущая чанковая загрузка.

Portable-вариант нужно целиком распаковать в одну папку и запустить ExWG.exe.
Переносить из архива только один файл нельзя: Flutter runtime и data являются
частью приложения. Сам установщик остаётся одним готовым EXE.

Окно Ex WG можно менять в пределах 980 × 640 — 1440 × 900. Полноэкранное
разворачивание отключено, чтобы интерфейс сохранял заданные пропорции.

ExWGCore.exe содержит проверенную копию Wintun. Отдельно копировать или скачивать
wintun.dll не требуется. Go, Flutter, Visual C++ Runtime и WebView2 пользователю
устанавливать не нужно.

Сборка не подписана сертификатом Authenticode. Windows SmartScreen может показать
предупреждение. Перед публичным распространением необходимы подпись и тесты на
чистой Windows 10/11.

Важно: эта версия использует официальный AWG core, локальный DNS и Windows route
table. FakeDNS=true явно не поддерживается. Полные Android-функции per-flow SNI/
Host classification и WFP Block в этой Windows-версии не заявлены.

Диагностика сохраняется локально и может содержать адреса серверов, DNS-запросы и
сведения о сети. Приватные ключи намеренно не включаются. Автоматической отправки нет.
